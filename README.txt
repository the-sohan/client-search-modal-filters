Client Search Modal Filters 1.1.0

Install or upgrade using the packaged ZIP in Plugins > Add New > Upload Plugin.
Replace the existing 1.0.0 version; keep only one copy active.
Requires Directorist, AddonsKit for Bricks, Bricks, WordPress 6.0+, PHP 7.4+.

Bricks: edit your header > select Search Modal > Content > Button > Show More Filters.
Choose Show or Hide and save. Existing elements default to Show.
The setting follows the element wherever Bricks renders that header.
Set the header template conditions as needed (for example Entire Website).
No fixed page slug, element ID, or code edits are required in version 1.1.0.
Advanced search fields must exist in the Directorist Directory Builder.

No Directorist, AddonsKit, or Bricks files are modified.
Deactivate to restore native behavior. The choice remains saved in Bricks element data.
See README.md for verification, requirements, and limitations.
