Client Search Modal Filters 1.0.0

Install the ZIP in Plugins > Add New > Upload Plugin, then activate.
Requires Directorist, AddonsKit for Bricks, and the Bricks theme.

Client scope: page slug aaa-brick-test; Bricks Search Modal element jlwxvn.
Only that element's search shortcode is changed. Other forms and modals are untouched.
If the destination client page or Bricks element ID differs, update PAGE_SLUG and
ELEMENT_ID in client-search-modal-filters.php before installing there.

More Filters expands inside the existing search dialog. The fields remain in
the native Directorist form; Apply Filters submits the native search request.
The Directory Builder must have advanced search fields configured.
Escape closes the filters first, then closes the search dialog on the next press.

Deactivate to restore the original modal. No database settings or core files are changed.
Retest after Directorist, Bricks, or AddonsKit updates.
